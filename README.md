# Manufacturing Website

A modern, responsive manufacturing company website built to showcase the company's products, services, capabilities, quality standards, and contact information.

## Features

* Responsive design for desktop, tablet, and mobile
* Professional homepage with hero banner
* About Us section
* Products and Services section
* Manufacturing capabilities
* Quality and certification section
* Industries served
* Why Choose Us section
* Contact/Inquiry form
* WhatsApp integration
* Google Maps/location section
* Responsive navigation and footer

## Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Bootstrap / Custom CSS
* React Router
* Axios

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project directory:

```bash
cd manufacturing-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The website will be available at:

```text
http://localhost:3000
```

## Production Build

To create a production build:

```bash
npm run build
```

The optimized website will be generated inside the `build` folder.

## Deployment

The project can be deployed using platforms such as Vercel or Netlify.
